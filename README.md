## Projeto Em Destaque

### Plataforma de Universidade Corporativa

Estou desenvolvendo uma plataforma completa de treinamento corporativo para empresas com colaboradores distribuídos em cargos, lojas, grupos e unidades diferentes.

A solução foi pensada para funcionar como um produto real, com áreas separadas para aluno, franqueado/gestor e administrador.

Principais recursos:

- Login com diferentes papéis de acesso.
- Área do aluno com trilhas, cursos, aulas, calendário, certificados, favoritos e ranking.
- Conteúdos liberados por cargo, grupo, loja ou usuário específico.
- Ranking segmentado por cargo, para comparação mais justa entre funções parecidas.
- Cursos com slides, vídeos, PDFs, quizzes, avaliação final e certificado.
- Player de vídeo com controle de progresso mínimo assistido.
- Editor visual de aulas com palco, linha do tempo, imagens, textos, quiz e certificado.
- Painel administrativo para gerenciar usuários, lojas, grupos, cargos, trilhas, cursos e acessos.
- Área para franqueado/gestor acompanhar evolução dos alunos de suas lojas.
- Indicadores gerenciais com aderência, conclusão, dedicação, certificados e alunos parados.
- Suporte a português e espanhol na interface.
- Preparação para produção usando Cloudflare Workers, D1, R2 e Mux.

Esse projeto representa uma virada importante na minha jornada: sair de soluções pontuais e construir uma plataforma completa, com arquitetura, experiência visual, regras de acesso, persistência, segurança e visão de negócio.
